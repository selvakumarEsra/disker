disky

Fast disk analyzer and cleanup for macOS, Linux and Windows, in Rust.

Scan 2 million files in minutes, diff snapshots, clean up safely into the Trash and restore later, pipe JSON to any agent, or use the desktop app. Alternative to ncdu, dust, du, GrandPerspective, DaisyDisk — built for the terminal AND for AI agents that shell out.

GitHub repo Releases Changelog

Install

cargo install --git https://github.com/selvakumarEsra/disker

Or download a binary from Releases: macOS and Linux tarballs (x86_64 and aarch64) and a Windows zip (x86_64). On Windows, building from source needs the Visual Studio 2022 C++ build tools.

Quick start

disky scan /                   # scan from root (~3 min, 2M files)
disky                          # ncdu-style TUI
disky top --physical           # largest files (APFS-aware)
disky cleanup --apply --reversible    # safe cleanup → Trash / Recycle Bin
disky history                  # every applied clean
disky restore <id>             # put it back
disky dupes                    # byte-identical files
disky large                    # files of 2 GB and over

Agent-native

Every command emits an envelope {schema_version, kind, records}. Errors on stderr follow RFC 9457. Exit codes are stable. Run disky schema for the machine descriptor.

Desktop app

A Tauri + SolidJS app on the same engine: Smart Clean, Space map, Large files, Duplicates, Assistant, History and Settings. It never deletes anything itself; everything it does, the CLI can do too. Build it with cd gui && npm install && npm run tauri build.
